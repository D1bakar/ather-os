# Drivers

> **Status:** Not started — initial drivers may live in `kernel/` during M1–M3.

Hardware drivers for Aether OS. Early milestones inline minimal drivers (e.g.,
16550 serial on COM1) inside the kernel tree for simplicity per
[ADR-0001](../docs/adr/ADR-0001-modular-monolithic-kernel.md).

Extracted or user-space drivers may appear here when isolation requirements justify it.
